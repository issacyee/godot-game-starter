# 模块契约模板

用于重要模块和跨模块语义，不要求每个类／私有函数单独填写。按实际需求精简，未启用能力写不适用，不为填表新增机制。签名链接到实现，本文只定义有效约定，不记录开发流水。参考 [架构](../guides/game-architecture.md) 与 [工作流](../workflow.md)。

## 身份与范围

- 目的、玩家可观察行为、明确非目标：
- 状态所有者、不变量、允许依赖、禁止依赖：
- 关联需求／规则、受影响模块、待确认决定：

## 请求、结果与事实

- 输入类型、单位／空间、合法范围、缺失与非法值：
- 请求入口、接受、正常拒绝、系统故障的区别：
- 事实名称、载荷、产生顺序、消费时机和有效期：
- 拒绝是否耗时／消耗资源，失败后状态与原子性：
- 值视图／借用引用／副本约束，谁可修改什么：

## 时序与生命周期

- 初始化／就绪、运行、暂停、继续、重开、关闭、部分失败：
- Godot 回调、时间来源、调用顺序、线程／重入约束：
- 重复调用、取消、过期目标、幂等与恢复：
- 节点／Resource／信号由谁创建、持有、借用和释放：
- 随机来源与复现范围（未使用则不适用）：

## 参数与数据

- [调参入口](../../tuning/README.md) 与权威定义：
- 类型、单位、合法／推荐范围、交叉约束和有效值来源：
- 启动／下一局／即时应用，快照或热重载策略：
- 请求、事件、内容 ID、参数键的兼容影响：
- 存档／完整快照的版本与逐步恢复影响（仅启用时）：

## 平台、副作用与诊断

- 目标平台的核心任务、能力限制与未验证项：
- 设备、物理、文件、网络、图形／音频等副作用执行者：
- 失败结果、降级、重试上限与恢复方式：
- 记录边界、稳定事件码、字段／隐私白名单、容量与丢弃策略：
- 构建／参数／操作关联、必要性能预算与测量方式：

## 验证

- 给定 → 操作 → 状态／事实／副作用预期：
- 正常、拒绝、边界、非法输入、重复、重开与失败分支：
- 无头规则、场景重载、真实输入、技术视觉分别如何验证：
- 表现重复调用与视图别名隔离：
- 完整恢复正例与删字段反例（仅启用时）：
- 现有测试入口、范围与限制；单次结果保留在产物报告，不复制进共享契约。
